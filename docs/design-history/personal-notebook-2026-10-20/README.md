# Personal notebook, October 2026

Selected direction: blend the Two Cities journey illustration with the Playful Commonplace palette. The signature is the illustrated San Francisco–Singapore line, supported by open editorial columns, colorful rules, and comfortable sans-serif reading. User feedback called for more generous mobile typography, and a desktop index that unfolds in the margin rather than appearing as a popover.

References: [the requested reading reference](https://jjmaxwell4.com/writing/hiring-your-first-employee-2026/index.html), [about swyx](https://swyx.io/about), [date-me page](https://swyx.notion.site/dateme), and the selected ImageGen directions in this directory. The production illustration is `static/assets/personal/two-cities.webp`.

The real implementation keeps the existing navigation, search, archive, article metadata, contents, book, newsletter and projects. Instead of copying invented mockup content, it uses existing public links and real content. At smaller widths both article disclosures expand in normal flow. The shelf shows one full essay at a time on phones with a scroll cue; its entries remain keyboard reachable. The reading column remains plain for contrast, with ambient color outside it.

Visual checks: Chrome local preview, light and dark home; `/ideas` archive and search; `/america250` article with contents and index expanded; 390px phone, tablet/split and desktop. Captures alongside this note are viewport screenshots; responsive measurements are CSS pixels. Final release verification should repeat desktop and phone against the deployed commit.
